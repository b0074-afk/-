## 🎯 프로젝트 개요

**골드런 승마랜드**는 일반 회원, 학교 승마, 자유 승마, 카페 등 모든 서비스를 하나로 통합한 종합 승마장 관리 플랫폼입니다.

### 🌟 핵심 가치

1. **노쇼 제로 도전** - 예약금 없이 스마트 알림으로 노쇼 방지
2. **긴급 슬롯 활용** - 학교승마 취소 시 즉시 일반 회원에게 알림
3. **4가지 역할별 최적화** - 회원/학생/코치/관리자 각각 맞춤 대시보드
4. **교육 중심** - 승마의 교육적 효과를 만화로 쉽게 설명
5. **호스피아 표준 연동** - 학교승마 정부 지원사업 완벽 연계

- 빠른 예약 버튼 (Quick CTA)

- **호스피아(Horsepia) 연동**
- 정부 지원 프로그램 안내
- 학교별 신청 현황
- 10회 출석 체크 시스템

#### 📅 일반 체험승마 예약
- 실시간 예약 가능 시간표

- 코치 선택 기능

```

2단계: 예약 24시간 전 알림
3단계: 예약 2시간 전 최종 확인
```

#### 🏇 회원승마 & 자유승마

- 출석률 관리
- 승마 일지 기록

#### 📚 승마의 효과 (교육 콘텐츠)
만화 스타일로 설명:
- **신체 발달**: 균형감각, 근력 향상

- **전인적 성장**: 집중력, 인내심, 자신감
- **치료 효과**: ADHD, 자폐 스펙트럼 개선

## 📖 사용 가이드

### 일반 회원 예약 플로우

```
1. 메인 페이지 접속
   ↓
2. "예약하기" 버튼 클릭
   ↓
3. 날짜 & 시간 선택
   ↓
4. 말 & 코치 선택
   ↓
5. 연락처 입력
   ↓
6. 예약 완료 (SMS 즉시 발송)
   ↓
7. 24시간 전 알림 수신
   ↓
8. 2시간 전 최종 확인 알림
   ↓
9. 현장 방문 (QR 체크인)
   ↓
10. 승마 체험 후 일지 작성
```

### 학교승마 신청 플로우

```
1. 호스피아 사이트 접속
   ↓
2. 학교 & 프로그램 선택
   ↓
3. 학생 정보 입력
   ↓
4. 신청 완료 (자동 연동)
   ↓
5. 골드런 시스템에 학생 등록
   ↓
6. 10회 수업 스케줄 자동 생성
   ↓
7. 학부모 알림 설정
   ↓
8. 출석 체크 (매 수업)
   ↓
9. 10회 완료 시 수료증 발급
```

### 긴급 슬롯 활용 플로우

```
1. 학교승마 취소 발생
   ↓
2. 시스템이 자동으로 긴급 슬롯 생성
   ↓
3. 대기자 명단에 푸시 알림 발송
   ↓
4. 선착순 예약 (5분 내)
   ↓
5. 예약 완료 시 슬롯 마감
   ↓
6. 다른 대기자에게 "마감" 알림
```

## 🛡️ 노쇼 방지 시스템

### 알림 타이밍

| 시점 | 방법 | 내용 |
|------|------|------|
| 예약 즉시 | SMS | "예약 완료! 날짜: XX, 시간: XX" |
| 24시간 전 | SMS + Push | "내일 예약이 있습니다. 확인해주세요." |
| 2시간 전 | SMS + Push | "2시간 후 예약입니다. 준비해주세요!" |
| 1시간 후 | 시스템 | 노쇼 체크 (미방문 시 자동 기록) |

### 노쇼 패널티 정책

```
1회 노쇼: 경고 (SMS 안내)
2회 노쇼: 다음 예약 시 보증금 5,000원
3회 노쇼: 1개월 예약 제한
4회 이상: 회원 자격 정지 (재검토)
```

### 정당한 취소 방법

- **24시간 전까지**: 무료 취소
- **24시간 이내**: 관리자 승인 필요 (사유 제출)
- **긴급 상황**: 전화 연락 후 처리

## 🔗 호스피아 연동

### 호스피아(Horsepia)란?

> 학생승마체험 지원사업의 표준 온라인 플랫폼
> - 운영: 한국마사회
> - 목적: 학생들의 승마 체험 기회 확대
> - 지원: 정부 보조금으로 저렴한 체험 가능

### 연동 시스템

```javascript
// API 엔드포인트 (예시)
GET /api/horsepia/sync
POST /api/horsepia/attendance
GET /api/horsepia/students/{id}
```

### 동기화 프로세스

1. **실시간 동기화**: 매 시간 자동 업데이트
2. **수동 동기화**: 관리자 대시보드에서 즉시 동기화 버튼
3. **출석 데이터 전송**: 수업 종료 후 자동 전송
4. **오류 처리**: 동기화 실패 시 관리자 알림

## 🛠️ 기술 스택

### Frontend
- **HTML5**: 시맨틱 마크업
- **CSS3**: 반응형 디자인, 그라데이션, 애니메이션
- **JavaScript (ES6+)**: 모던 문법, 비동기 처리
- **Font**: Pretendard (한글 최적화)
- **Icons**: Emoji + Custom SVG

### Backend (권장)
- **Node.js + Express** 또는 **Python + FastAPI**
- **PostgreSQL** 또는 **MySQL**
- **Redis**: 캐싱 및 실시간 알림
- **JWT**: 인증/인가

### 외부 서비스
- **SMS 발송**: Aligo, KakaoTalk API
- **Push 알림**: Firebase Cloud Messaging
- **결제**: 토스페이먼츠, 네이버페이
- **호스피아 API**: 공식 연동 API
